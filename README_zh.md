## 📖 愿景

在 AI 时代，算力和专有算法正在制造新的数字鸿沟。**AltAI**（Alternative AI）是一个由社区驱动的精选项目集合，致力于 **AI 平权**。

我们的使命是识别、整理并推广那些能够作为主流商业软件**真正替代选择**的开源 AI 项目。我们不是为了取代谁——我们只是为每一个用户**增加一种选择**。

> *无所谓取代，只是多一种选择。*

### 🎯 什么是“新型格式世界”？

这是一种平衡状态，让用户拥有**真正的多项选择**：

- 你可以使用 **ChatGPT Plus**，**还可以**使用 **OpenAssistant** 或 **Vicuna**（本地运行）
- 你可以使用 **Midjourney**，**还可以**使用 **Stable Diffusion** + **ComfyUI**
- 你可以使用 **GitHub Copilot**，**还可以**使用 **CodeLlama** + **Continue**
- 你可以使用 **ElevenLabs**，**还可以**使用 **Piper** 或 **Bark**

更多选择意味着更多自由——隐私的自由、成本的自由、定制的自由。我们相信，在软件世界里，**平权来自于选择，而不是垄断**。

### 🤝 如何贡献

我们需要你一起构建一个拥有更多选择的世界。你可以：

1. **添加项目** – 提交 PR，补充缺失的商业软件替代品。
2. **平权评分** – 帮助我们对开源项目与商业版的接近程度进行打分。
3. **代码贡献** – 参与需要帮助的子项目（查看 issue）。
4. **传播理念** – 告诉更多人：还有另一种选择。

### 📜 原则

- **无所谓取代，只是选择** – 我们共存，而非竞争。
- **隐私优先** – 你的数据尽可能留在你自己手中。
- **开放权重** – 模型应当可下载，而不仅仅是 API 访问。
- **社区治理** – 没有企业的后门控制。
